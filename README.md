Token Radar ranks 226 pre-token DeFi protocols by implied token value, calibrated from the live-token market in the same snapshot — category by category, not a flat multiple. Every row carries a 7-step farm plan with costs and times.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts --input <snapshot.json>
```
